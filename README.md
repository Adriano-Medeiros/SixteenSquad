# SixteenSquad

O **SixteenSquad Starter** é uma base reutilizável para projetos no Codex. Reúne um Coordenador, 15 perfis nativos de especialistas, 16 skills, modelos de trabalho e um validador com testes.

Consulte o [guia do Starter](starter/README.md) para instalar manualmente os componentes em um projeto novo, verificar o pacote e conhecer suas limitações. As especificações avançadas do framework não fazem parte desta publicação.
